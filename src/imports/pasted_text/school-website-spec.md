Build a modern, premium, enterprise-grade school website for a smart educational institution that is powered by a complete School ERP ecosystem.

The website must reflect innovation, trust, academic excellence, and digital transformation.

Tech Stack Requirements:

* React 19
* TypeScript
* Vite
* Tailwind CSS
* Shadcn UI
* TanStack Query
* React Router
* Framer Motion
* Lucide Icons
* Responsive Mobile-First Design
* Dark Mode Support
* Modern Component Architecture (Feature-Based Structure)

Design Requirements:

* Premium modern UI similar to Apple, Stripe, Linear and Notion
* Clean white background with soft purple primary branding
* Glassmorphism effects
* Soft shadows
* Rounded corners (24px+)
* Smooth animations
* Interactive cards
* Elegant typography
* Consistent Design System
* Professional educational branding

The website should feel like a modern EdTech platform, not a traditional school website.
